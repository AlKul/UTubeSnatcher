# UTubeSnatcher

Telegram-бот для скачивания публичных YouTube-видео и извлечения аудио в MP3.
Проект использует `aiogram 3` и `yt-dlp`.

> Используйте бот только для материалов, которые вам принадлежат или которые
> разрешено скачивать. Соблюдайте условия YouTube и авторские права.

## Возможности

- обычные ссылки YouTube, `youtu.be`, Shorts и Live;
- скачивание видео в MP4;
- извлечение аудио в MP3;
- контроль размера файла перед отправкой;
- временные каталоги с гарантированной очисткой;
- таймауты и понятные сообщения об ошибках;
- учёт пользователей, скачиваний, объёма и ошибок в SQLite;
- закрытая статистика администратора через `/stats`;
- стабильный Telegram user ID и username, если пользователь его установил;
- дневные лимиты для free/premium и защита от одновременного обхода лимита;
- блокировка пользователей и переключение тарифов администратором;
- maintenance-режим без прерывания уже запущенных загрузок;
- HTTP healthcheck и автоматические проверки GitHub Actions;
- токен и лимиты только через переменные окружения.

## Быстрый запуск

Требуются Python 3.11+ и `ffmpeg`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Добавьте в .env новый BOT_TOKEN, полученный у @BotFather
python main.py
```

## Docker

```bash
docker build -t utube-snatcher .
docker run --rm --env-file .env utube-snatcher
```

## Проверки

```bash
pip install -r requirements-dev.txt
pytest
ruff check .
```

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `BOT_TOKEN` | — | Обязательный токен Telegram-бота |
| `MAX_UPLOAD_MB` | `49` | Предельный размер отправляемого файла |
| `DOWNLOAD_TIMEOUT_SECONDS` | `600` | Таймаут одной загрузки |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `DATABASE_PATH` | `data/utube_snatcher.sqlite3` | Локальная база статистики |
| `ADMIN_USER_IDS` | — | Telegram user ID администраторов через запятую |
| `REQUIRE_USERNAME` | `false` | При необходимости запретить аккаунты без username |
| `FREE_DAILY_LIMIT` | `5` | Дневной лимит бесплатного тарифа |
| `PREMIUM_DAILY_LIMIT` | `100` | Дневной лимит premium-тарифа |
| `PORT` | `8080` | Порт healthcheck `/health` |
| `HEALTH_HOST` | `0.0.0.0` | Адрес healthcheck-сервера |

Узнать собственный Telegram user ID можно командой `/whoami`. После добавления
ID в `ADMIN_USER_IDS` администратору доступны:

- `/stats`, `/stats 30d` — статистика за период;
- `/maintenance on|off` — приостановить или возобновить новые загрузки;
- `/plan USER_ID free|premium` — изменить тариф;
- `/block USER_ID` и `/unblock USER_ID` — ограничить или вернуть доступ.

Пользователь может посмотреть свой остаток командой `/quota`. Лимиты
сбрасываются в 00:00 UTC.

База хранит стабильный Telegram `user_id`, текущее имя, доступный username,
снимок username для каждого скачивания, формат, результат, размер файла и время
обработки. Username может отсутствовать или меняться, поэтому ограничения нужно
привязывать именно к `user_id`. Полные YouTube-ссылки и названия роликов не
сохраняются.

## Надёжный запуск

Для постоянной работы используйте Docker Compose:

```bash
docker compose up -d --build
docker compose ps
```

Контейнер автоматически перезапускается после сбоя, база хранится в отдельном
Docker volume, а `/health` сообщает состояние процесса и maintenance-режима.
Перед обновлением включите `/maintenance on`, дождитесь завершения активных
загрузок, обновите контейнер и выключите режим командой `/maintenance off`.

GitHub Actions автоматически запускает тесты, Ruff и сборку контейнера для
каждого pull request. Секретный `.env` никогда не должен попадать в GitHub.

## Почему старая версия была переписана

В прототипе одновременно существовало несколько обработчиков и диалогов,
использовались `pytube`, `moviepy` и ручное переименование аудиофайла. Были
жёсткие локальные пути, код выполнялся при импорте, а токен хранился в исходнике.
Текущая версия оставляет один рабочий поток и минимальный набор зависимостей.
